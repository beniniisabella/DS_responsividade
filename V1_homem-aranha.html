05 · O primeiro passo no HTML

Antes do CSS, o viewport.

É a área visível usada pelo navegador para exibir a página. A tag abaixo permite que a largura do layout acompanhe a largura do dispositivo.

Ela prepara o terreno.

Mas quem organiza o layout de forma responsiva é principalmente o CSS.

<meta name="viewport"
content="width=device-width,
initial-scale=1">
06 · Medidas inteligentes

Nem tudo precisa de um tamanho fixo.

% e vw

Respondem ao espaço relativo — do elemento pai ou da viewport.

rem

Usa como referência o tamanho da fonte do elemento raiz.

clamp()

Define mínimo, tamanho desejado e máximo em uma mesma regra.

.titulo { font-size: clamp(2rem, 5vw, 5rem); }
.container { width: min(90%, 1200px); }
07 · Layouts que respiram

Flexbox + Grid.

Duas ferramentas diferentes que resolvem muitos problemas de organização sem precisar definir posição pixel por pixel.

Flexbox

Distribui e alinha elementos ao longo de um eixo. Ótimo para menus, barras e grupos de botões.

CSS Grid

Organiza linhas e colunas. Ideal para galerias, dashboards e estruturas maiores.

08 · Uma técnica poderosa

Cards que se organizam sozinhos.

Em vez de fixar sempre três colunas, podemos pedir ao navegador para encaixar o máximo de colunas que couberem.

auto-fitminmax()1fr
.cards {
display: grid;
grid-template-columns:
repeat(auto-fit,
minmax(min(100%, 220px), 1fr));
gap: 1rem;
}
09 · Quando o layout precisa mudar

Conheça as media queries.

São condições no CSS. Elas aplicam estilos específicos quando características como a largura da viewport atendem à regra.

Breakpoint ≠ modelo de celular.

O melhor ponto de quebra é onde o seu conteúdo precisa de outra organização.

.cards {
display: grid;
grid-template-columns: 1fr;
}

@media (min-width: 768px) {
.cards {
grid-template-columns: repeat(3, 1fr);
}
}
10 · Estratégia de construção

Começar pequeno para pensar grande.

Mobile-first é estruturar os estilos básicos para telas menores e adicionar melhorias quando houver mais espaço.

✓
Ajuda a priorizar o conteúdo essencial.
✓
Incentiva layouts mais simples e flexíveis.

Pergunta rápida

Mobile-first significa que o site só precisa funcionar no celular?

Não. Significa começar pelo layout menor e expandir a experiência para outras larguras, incluindo desktop.
11 · Imagens e mídia

Imagens que não estouram a tela.

Uma imagem também deve respeitar o espaço disponível. Quando necessário, podemos controlar o recorte sem deformar a proporção.

max-width: 100%height: autoobject-fit
img {
max-width: 100%;
height: auto;
}

.capa {
aspect-ratio: 16 / 9;
object-fit: cover;
}

14 · Ferramentas do desenvolvedor

Como testar de verdade?

Abra o site no navegador e pressione F12.

Ative o modo de dispositivo nas DevTools.

Altere a largura e verifique rolagem, menus, imagens e botões.

Teste também o uso real: toque, teclado e diferentes navegadores.
